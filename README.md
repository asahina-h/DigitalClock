# Digital Clock

## 概要

Java Swingで作成した、デスクトップ上に常時表示するデジタル時計アプリケーションです。

ウィンドウの枠をなくした半透明の時計を画面右下に表示し、現在の日付と時刻を確認できます。表示サイズや背景色を変更する機能も備えています。

## 主な機能

- **日付・時刻の表示**
  - 日付、時刻（時・分・秒）を表示します。
  - 時刻は1秒ごとに更新されます。
  - 秒の文字サイズを小さくして表示します。
  - ウィンドウのサイズに応じて日付の表示形式を切り替えます。

- **常に最前面に表示**
  - 他のウィンドウを開いても、時計が前面に表示されます。

- **半透明・枠なし表示**
  - ウィンドウの枠を非表示にし、透過度70%で表示します。

- **表示サイズの切り替え**
  - ダブルクリックでウィンドウの横幅を切り替えます。
  - 大サイズ：幅240px
  - 小サイズ：幅170px
  - 高さ：80px

- **ウィンドウの移動**
  - マウスでドラッグして表示位置を変更できます。

- **背景色の変更**
  - 右クリックメニューから背景色を選択できます。
  - 選択した背景色は設定ファイルに保存されます。

- **アプリケーションの終了**
  - 右クリックメニューの「閉じる」から終了できます。

## 操作方法

| 操作 | 動作 |
|---|---|
| ダブルクリック | 表示サイズの切り替え |
| 左クリックしたままドラッグ | ウィンドウの移動 |
| 右クリック | メニューを表示 |
| 「背景色を変更」 | 背景色を選択・保存 |
| 「閉じる」 | アプリケーションを終了 |

## 設定ファイル

背景色の設定には `config.properties` を使用します。

### 設定内容

```properties
background.color=255,255,255
```

RGB形式で背景色を指定します。

- `255,255,255`：白
- `0,0,0`：黒
- `255,0,0`：赤

アプリケーション起動時に設定ファイルを読み込み、背景色を適用します。設定ファイルが存在しない場合や読み込みに失敗した場合は、白色で表示します。

背景色を変更すると、選択したRGB値が設定ファイルに保存されます。

## 起動方法

### Eclipseから起動する場合

1. Eclipseで本プロジェクトを開きます。
2. `src` 内の `example.Clock.java` を開きます。
3. ファイルを右クリックします。
4. 「実行」→「Javaアプリケーション」を選択します。

### 必要なファイル

- `src/example/Clock.java`：時計アプリケーションのソースコード
- `config.properties`：背景色の設定ファイル
- `.project`、`.classpath`：Eclipseプロジェクトの設定ファイル

`.settings`、`build` などのフォルダも、プロジェクトの構成に応じて使用します。

## 使用技術

- Java
- Java Swing（GUI）
- AWT（ウィンドウ制御・マウスイベント）
- `java.util.Properties`（設定管理）
- `java.text.SimpleDateFormat`（日付・時刻の書式設定）

## 注意事項

- 画面右下への初期配置は、タスクバーが画面下部にあることを想定しています。
- 背景色の設定ファイルは、実行時の作業ディレクトリを基準に読み書きします。
- ウィンドウの透過表示には、実行環境が対応している必要があります。
